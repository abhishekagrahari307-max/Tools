Image converter

Pick images and choose the format you need. PNG keeps sharp edges and transparency; JPG and WebP give much smaller files for photographs.

    Quality 88%

    Tips: use PNG for logos and screenshots, JPG for photos, WebP when the recipient opens files in a modern browser. Compress first with the image compressor if you need a smaller file at the same format.

    Image resizer

    Shrink photos for a form, a website or a chat. “Fit inside” keeps the aspect ratio, “Exact size” stretches to the numbers you type, and “Percent” scales the original.

      JPEG / WebP quality 90%

      PDF merger

      Add the PDFs in the order you want them. Use the arrows to reorder, then download one combined document. Pages keep their original size and quality.

        PDF compressor

        Two honest options. Clean up rewrites the file without unused objects — good for exported documents, harmless to text. Shrink pages turns each page into a picture, which can cut scans sharply but removes selectable text.

          Picture quality 62%

          If the result is not smaller, keep your original. PDFs that are already optimised or contain a single compressed photo often cannot shrink much.

          PDF to Word

          Reads the text of each page and writes a real .docx you can open in Word, Google Docs or LibreOffice. Page breaks are kept. Scanned PDFs without a text layer cannot be converted here — there is no text to lift out.

            Need the pages as pictures or a merged file instead? Use the PDF compressor or PDF merger above.
